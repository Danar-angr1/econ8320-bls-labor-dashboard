# Econ8320-bls-labor-dashboard

## Project

This project was built to expand and analyze data collected from the U.S. Bureau of Labor Statistics (BLS). Python will be used as a tool to help interact with the user and create a polished account of the monthly U.S. labor market.

The project will collect, organize, and present monthly labor market statistics so that users can better understand the changes and trends in the U.S. labor market over time.

- Values represent what each month's inputs were.
- The trends in the data set will be shown through different visuals and graphs.
- Referenced work will be provided for the reader to collect and incorporate their own research.
- The dashboard will allow users to interact with the data and better understand changes and trends in the U.S. labor market over time.

## Tools

The tools used for this project are built into the Python library and are free and accessible to users. The goal is to use these tools to make the project easier to update and allow the statistics to continue improving as new monthly data becomes available.

The main tools and sources will include:

- **Python** – Used to collect, process, organize, and work with the data.
- **Pandas** – Used to clean, organize, and analyze the collected data.
- **BLS Public API** – Used to collect monthly labor market statistics directly from the U.S. Bureau of Labor Statistics.
- **Streamlit** – Used to create the interactive dashboard and present the data through visuals and graphs.
- **Google Colab** – Used as a Python development environment for working with and testing the project.
- **GitHub** – Used to store the project code, data, and documentation and to allow the project to be updated over time.

These tools allow the project to remain accessible and provide a way to continue incorporating new and updated statistics as they are released.

## Planned Data

The project will focus on monthly U.S. labor market data collected from the BLS Public API. The dashboard will include the required labor statistics along with additional series selected to provide a broader view of the labor market.

### Required Data

- **Total Nonfarm Employment** – Measures the total number of workers employed in nonfarm industries.
- **Unemployment Rate** – Measures the percentage of the civilian labor force that is unemployed.

### Additional Planned Data

- **Labor Force Participation Rate** – Shows the percentage of the civilian population that is participating in the labor force.
- **Average Hourly Earnings** – Shows changes in average hourly earnings over time.
- **Total Private Employment** – Shows the number of workers employed in the private sector.

The data will contain at least one year of previous monthly information so that trends can be compared over time. As new BLS statistics are released, the project will collect and add the newest month's information to the existing data set.

The dashboard will use different visuals and graphs to show changes in employment, unemployment, labor force participation, and wages. This will allow the user to interact with the information and view trends rather than only looking at individual monthly values.

The project will also provide referenced work and sources so that readers can understand where the statistics came from and use the information for additional research.

## Project Goal

The overall goal of this project is to create a useful and interactive tool for viewing U.S. labor market statistics. The project will combine data collection, data cleaning, visualization, and automation to create a dashboard that can continue to be updated as new monthly BLS statistics are released.

The project will also demonstrate how different free and accessible tools can be combined to collect and present real-world economic data in a way that is easier for users to understand and explore.
